01

Get access and create the post

Every Cytron tutorial is written and published in WebAdmin. A tutorial page shows how a product works before a customer orders, and it is where customers and customer support staff come back to. Write every step for a complete beginner.

    Tick the steps as you go. Your ticks stay in this browser only.

    02

    Fill every WebAdmin field

    Every field is compulsory, and a tutorial with an empty or incomplete SEO field is not ready to publish. Practise here, then copy the values into WebAdmin. Nothing you type is saved or sent.

    Example values filled in.
    Post Name
    Short and clear. No numbers unless required. Not repeated in the body.
    PitchMeta Tag Description

    Not shown on the page. One complete, unique sentence: Build a/an [project] using [main board] and [main part] to [outcome]. A Protip can start with the outcome instead, e.g. Fix ….

    Description

    The tutorial body. Write it by following step 03.

    Post Tags

    The board family and main board first (e.g. ESP32, Maker ESP32), then the main modules, protocols and topic.

    Meta Tag Keywords
    3 to 8 keywords, comma-separated. Never paste the Pitch here.
    Meta Tag Title
    Shown in search results and browser tabs: Post Name plus the key technology.
    Context Menu

    Target audience. Choose one only.

    SEO URL
    Filled from Post Name. Lowercase, hyphens for spaces, no special characters.

    Set it first. It names the image folder, and it must never change after publishing.

    Image Folder Name

    Filled in by WebAdmin and locked. It does not follow later SEO URL changes, so get the SEO URL right before you first save.

    Publish Date

    The actual publish date, not the date you started writing.

    Post Type

    Project Level

    Status

    Sort Order

    1 for a standalone tutorial. In a series, number the parts in order: 1, 2, 3. Use another number only when your supervisor asks.

    Author

    Your name from the dropdown.

    Categories

    The categories that match the content, e.g. Wireless & IoT > Maker ESP32.

    Store Name

    Tick every store first. Untick a store only when a Related Product isn't sold there.

    Parent

    Series only: the main post (for example the series hub) this part belongs to. Empty for a standalone tutorial.

    Related Post

    Existing posts on the same topic, e.g. Getting Started with Maker ESP32.

    Related Product

    Exactly the items in List of Components, no more and no less. A kit tutorial attaches the kit. A Protip can attach only the main board. Use the variation product code (the parent product with options) where one exists.

    This fills the Hardware Components block below the body.

    The thumbnail is 16:9, preferably 1280 × 720, about 300 KB (1 MB at most), with the title in the image. Keep it minimalist: clear pictures of the products used only, no photo of the real build needed. Drop a picture here to check it before you upload.

    1280 × 720
    Must
    Minimalist: product pictures only on a plain background, few colours, the Cytron logo. No photo of the real build needed. Check nothing got cut off by background removal. A kit tutorial shows the kit.
    Must
    Every part of a series has its own thumbnail.

      Add a picture
      
            
      1. Save the picture as PNG or JPEG on your computer.
      2. Click the Image button. In Image Properties, click Browse Server.
      3. The S3 Image Manager opens on your folder, tutorial/your-seo-url. Click the blue Upload button, choose the file, wait for "Success: Your file has been uploaded!".
      4. Click the picture to insert it.
      5. Keep the ratio lock on. Set the width to 800 px only if the picture is wider. Click OK.
      
            
            
          
      
          
      Add the Telegram banner
      
            
      1. Download the banner from the Community Banner folder and upload it into your SEO URL folder.
      2. Put the cursor on an empty line at the very end and click Align Center.
      3. Image button, Browse Server, click the banner.
      4. Set the width to 900 px with the ratio lock on.
      5. In the Link tab, paste the community's Telegram link.
      6. Target: New Window (_blank). Click OK, save, and click the banner on the page to check it.
      
            
          
      
          
      Add a link
      
            
      1. Copy the URL of the page.
      2. Highlight the words and click the Link button (Ctrl + L).
      3. For a cytron.io page, set the protocol to <other> and paste only the SEO URL, e.g. /p-maker-esp32. For other sites, paste the full URL.
      4. Target tab: New Window (_blank). Click OK.
      
          
      
          
      Add code
      
            
      1. A few command lines: the editor's Computer Code style, on their own line. Shift+Enter for a new line. Never use it for a word inside a sentence.
      2. Longer code: log in to GitHub (staff: your own account; interns: the intern account, ask your supervisor for access and Mat Liven for the authentication code). Create a Public Gist with a title and file name and copy the embed code.
      3. Click Source in the editor and paste the embed code where the code belongs.
      
          
      
          
      Embed a YouTube video
      
            
      1. On YouTube: Share > Embed. Tick Start at if needed. Copy the code.
      2. In the editor, click Embedded YouTube Video, paste and click OK.
      
          
      
          
      Edit pictures in Canva
      
            
      Use the team Canva account (ask Ms. Hamimah, Mr. Solehin or Ms. Iffah for the login code). Save designs in Projects > 2025 Trainees > your own folder, and download as PNG limited to 300 KB.

      05
      Credentials: zero tolerance
      
        
      Never publish a real password, token or key, anywhere on a tutorial page. Every rule here is Must.
      
      
      This is the most serious rule in the guide.
        
      The Q4 2026 quick scan keeps finding real Blynk tokens, Telegram bot tokens and Wi-Fi passwords in published Cytron tutorials: in Gists, in code typed into the page and in a public GitHub repo. Anyone who copies one can take over that device, bot or account.
      
      
      Use these placeholders
      
      
      
      
      Where they leak
      
      
      • Gists, old revisions included
      • Code typed into the page body
      • Serial Monitor screenshots
      • Blynk Console screenshots
      • BotFather chat screenshots
      • Browser address bar
      • Videos
      • ZIP and Drive downloads
      • GitHub repos
      
      
      Rules
      
      
      
      
      Check your code
      
      
      
        
      Paste a sketch or Gist. It looks for real-looking passwords, tokens and keys, runs in your browser only, and sends nothing. It catches common patterns, so still read the code yourself.
      
        
        
      
        
      
      
      
      
      If a real credential is already published
      
      
      
      
      Removing the value without revoking it does not fix the leak: Gist revisions, Git history, search caches and readers who copied it still hold it.
